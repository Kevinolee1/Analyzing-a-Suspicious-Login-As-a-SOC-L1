# Analyzing-a-Suspicious-Login-As-a-SOC-L1
Investigated a suspicious login alert as a SOC Level 1 analyst by reviewing authentication logs, source IP and geolocation data, login timestamps, and user activity.
![Image alt](https://github.com/Kevinolee1/Analyzing-a-Suspicious-Login-As-a-SOC-L1/blob/9714509de284738e3c1899904e32d3751382d24d/Screenshot%202026-08-18%20011200.png)
Sign in to your designated SOC Level 1 analyst account.
![Image alt](https://github.com/Kevinolee1/Analyzing-a-Suspicious-Login-As-a-SOC-L1/blob/92badfe4eb8cd9a93c6846db57919ea2b640b6ad/Screenshot%202026-08-18%20011228.png)
Select the Suspicious Login ticket to begin the investigation.
![Image alt](https://github.com/Kevinolee1/Analyzing-a-Suspicious-Login-As-a-SOC-L1/blob/f72262bf65b711450f854f4d4c6f08797865c7af/Screenshot%202026-08-18%20011524.png)
Scroll down to the Post Reply section. Enter the actions taken by the SOC L1 analyst, along with the appropriate ticket disposition. Once the information has been documented, click Post Reply to submit the update.
![Image alt](https://github.com/Kevinolee1/Analyzing-a-Suspicious-Login-As-a-SOC-L1/blob/55e2f8f6c6f5bc3c1d01b0d929a47aeb26a6a1b9/Screenshot%202026-08-18%20012004.png)
Click Internal Notes, document your investigative findings and relevant observations, then select Post Note to save the entry to the ticket.
![Image alt](https://github.com/Kevinolee1/Analyzing-a-Suspicious-Login-As-a-SOC-L1/blob/8ae7debc5a23ad88c43221b64bb42cc1ee305b88/Screenshot%202026-08-18%20012031.png)
